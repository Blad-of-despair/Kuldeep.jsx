# Kuldeep Maurya — Portfolio

A modern, responsive personal portfolio built with **React**, **Vite**, **Framer Motion**, and **GSAP**, featuring dynamic live GitHub repository fetching, a theme customizer with multiple color presets, and interactive project showcases.

---

## ✨ Features

- **Live GitHub Integration**: Dynamically fetches your latest top 5 repositories from GitHub (`Blad-of-despair`) with smart caching and fallback support.
- **Interactive Carousel**: Showcases projects with smooth slide animations, navigation arrows, preview peek cards (left/right blurred cards), and dot indicators.
- **Dynamic Theme Customizer**: Switch between Dark Mode, Light Mode, Cherry Blossom, Ocean, Sunset, and Forest themes instantly with persistent state.
- **Smooth Animations**: Powered by GSAP ScrollTrigger and Framer Motion for elegant scroll reveals and card transitions.
- **Responsive Design**: Fully responsive layout optimized for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: CSS Modules, CSS Custom Properties (Variables)
- **Animations**: Framer Motion, GSAP (ScrollTrigger)
- **Icons**: React Icons (FontAwesome, Heroicons)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Blad-of-despair/Kuldeep.jsx.git
   cd Kuldeep.jsx
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
